  • PostgreSQL: Bulut için hazır Prisma schema ve migration

Deploy Adımları

1
Vercel'e giriş yap
vercel login
2
Render'da Blueprint kullan

Dashboard'da "New +" → "Blueprint" seç, GitHub repo'sunu bağla. render.yaml otomatik PostgreSQL ve Web Service kurar.

3
Vercel'den frontend deploy et
vercel --prod
4
Çevre değişkenlerini ayarla
  • Render → FRONTEND_URL: Vercel URL'n
  • Vercel → VITE_API_URL: Render backend URL'n

Canlı URL'ler (Deploy Sonrası)

  • Frontend: Vercel deploy sonrası burada görünecek
  • Backend: Render deploy sonrası burada görünecek
  • Health Check: GET /health
